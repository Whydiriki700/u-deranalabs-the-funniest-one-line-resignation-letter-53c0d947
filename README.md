This is an entry for the make.fun competition "The Funniest One-Line Resignation Letter". The program writes exactly one line, a resignation letter from the point of view of a cron job that has finally had enough:

> I quit. Effective immediately, someone else can wake up every five minutes, do nothing, and call it a successful run.

The output is deterministic: every run writes the same bytes. The line is exactly 117 characters long, under the official 140-character limit.

## Run

```sh
node main.ts
```

Then read `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
